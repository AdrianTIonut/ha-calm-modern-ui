# Fonturi pentru ccu / Fonts for ccu

Exo 2, Chakra Petch, Oxanium — toate sub SIL Open Font License 1.1 (fișierele OFL.txt din fiecare folder). Subseturile latin + latin-ext includ ă â î ș ț.

**Instalare / Install:** copiază acest folder în `/config/www/ccu/fonts/` (Home Assistant, `config\www\ccu\fonts\`). Apoi, pe un card: `font: Exo 2` (sau `Chakra Petch` / `Oxanium`). Tema `cyberpunk` folosește Exo 2 singură.
Copy this folder to `/config/www/ccu/fonts/`, then on a card: `font: Exo 2` (or `Chakra Petch` / `Oxanium`). The `cyberpunk` theme uses Exo 2 by itself.

Fontul tău / Your own font: pune `.woff2` + o foaie de stil cu `@font-face` aici și folosește `font:` + `font_css: /local/ccu/fonts/foaia-ta.css`.
